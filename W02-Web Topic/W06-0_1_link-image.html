ผลลัพธ์

โค้ด HTML

1  <img src="images/campus.jpg" alt="ภาพมหาวิทยาลัย"
    width="220">
2  <img src="images/student.jpg" alt="นักศึกษากำลังเรียน"
    width="180">
3  <img src="images/logo.png" alt="โลโก้วิชา"
    height="80">

🎯 จุดประสงค์การเรียนรู้

  1. อธิบายการใช้งานแท็ก <a> เพื่อสร้างลิงก์ไปยังหน้าเว็บหรือแหล่งต่าง ๆ
  2. แทรกรูปภาพด้วยแท็ก <img> พร้อมกำหนดคุณสมบัติพื้นฐาน
  3. ตกแต่งลิงก์และรูปภาพด้วย CSS เพื่อความสวยงามและน่าใช้งาน

🏷 แท็กที่ใช้บ่อย

<a>hreftarget<img>srcaltwidthheight

📋 กิจกรรมฝึกปฏิบัติ

  1. สร้างลิงก์อย่างน้อย 3 แบบ
  2. แทรกรูปภาพอย่างน้อย 2 รูป
  3. ใส่ alt ให้ทุกรูปภาพ
  4. ใช้ CSS แต่งสีและเมื่อ hover
  5. ตกแต่งด้วย border-radius หรือ box-shadow
  6. บันทึกไฟล์ชื่อ “link-image.html”

ส่งไฟล์ HTML พร้อมไฟล์รูปภาพ
i
เกร็ดความรู้
แท็ก <a> ใช้สำหรับสร้างลิงก์ (Hyperlink) เชื่อมโยงไปยังหน้าเว็บ ไฟล์ หรือที่อยู่อีเมลต่าง ๆ โดยใช้แอตทริบิวต์ href ระบุปลายทางของลิงก์ แท็ก <img> ใช้สำหรับแทรกรูปภาพ โดยต้องกำหนด src ระบุแหล่งที่อยู่ของไฟล์รูปภาพ และ alt ระบุข้อความอธิบายรูปภาพ ซึ่งสำคัญต่อการเข้าถึง (Accessibility) และช่วยให้แสดงข้อความเมื่อไม่สามารถโหลดรูปได้ CSS สามใช้ตกแต่งลิงก์ด้วย link color เอฟเฟกต์เมื่อ hover ขนาดของรูปภาพม ขอบ(border), มุมโค้ง(border-radius) และเงา(box-shadow) เพื่อให้หน้าเว็บสวยงามและน่าใช้งานมากยิ่งขึ้น
